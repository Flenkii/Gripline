Gripline V7.1 – Keyboard bindings / Tastenbelegung
========================================================================
Default bindings. Change them in FH2_Keyboard.ini next to azimuth.exe (several keys with a
comma, e.g. Throttle=W,Up; the key names are listed at the top of the file).
Standard-Belegung. Ändern: FH2_Keyboard.ini im Azimuth-Ordner (mehrere Tasten mit Komma).

FAHREN / DRIVING
  W                  Gas                          Throttle
  S                  Bremse / Rückwärts           Brake / reverse
  A / D              Lenken                       Steer
  Leertaste          Handbremse                   Space: handbrake
  E / Q              Hoch- / Runterschalten       Shift up / down
  Linke Shift-Taste  Kupplung                     Left Shift: clutch

KAMERA & BLICK / CAMERA & LOOK
  Pfeiltasten        Kamera bewegen (beim Fahren) Arrow keys: camera (while driving)
  Tab                Kamera wechseln (+Dashboard-Cam) Change camera (incl. dashboard cam)
  C oder Num2        Blick zurück                 Look back
  Num4 / Num6        Blick links / rechts         Look left / right
  N                  Nitro (nur mit NitroSystem)  Nitro (only with NitroSystem)
  V                  Dashboard-Cam ein/aus    Dashboard cam on/off

FUNKTIONEN / FUNCTIONS
  R                  Zurückspulen                 Rewind
  T                  Telemetrie                   Telemetry
  P                  Fotomodus                    Photo mode
  L                  Licht                        Headlights
  M                  Karte                        Map
  Minus / Plus       Radio zurück / weiter        Radio previous / next

GRIPLINE
  F5                 Tastenliste ein/aus          Key list on/off
  F6                 Noclip ein/aus (offline)     Noclip on/off (offline)
  F7                 Freecam ein/aus (offline)    Freecam on/off (offline)
  F8                 Gripline-Menü                Gripline menu
  F                  Aussteigen/Laufen (offline)  Get out / walk (offline)
  K                  Tempomat ein/aus             Cruise control on/off

NOCLIP (wenn an / while on)
  W / S              Vorwärts / rückwärts fliegen Fly forward / back
  A / D              Drehen                       Turn
  Leertaste / Strg   Steigen / sinken             Space / Left Ctrl: up / down
  Linke Shift-Taste  Schneller (halten)           Left Shift: faster (hold)

MAUS IM MENÜ (V7.1) / MOUSE IN THE MENUS (Esc)
  Maus über Kachel   Kachel auswählen             Mouse over a tile: select it
  Linksklick         Öffnen                       Left click: open
  Mausrad            Reiter oben / Listen         Wheel: tabs at the top / scroll lists
  Rechtsklick        Zurück                       Right click: back

MAUS-BLICK IM AUTO (V7.1) / MOUSE LOOK IN THE CAR
  Maus bewegen       Kamera drehen (jede Ansicht)  Move the mouse: turn the camera (every view)
  Maus 2 s in Ruhe   beim Fahren zurück zur Mitte  Mouse left alone 2 s while driving: back
  (Stillstand: Kamera bleibt / standing: it stays. Aus bei Maus-Lenkung / off with mouse steering)

LAUFEN (wenn ausgestiegen) / WALKING (when out of the car)
  W A S D            Laufen                       Walk
  Maus / Pfeiltasten Umschauen                    Mouse / arrow keys: look around
  Linke Shift-Taste  Rennen                       Left Shift: run
  Leertaste          Springen                     Space: jump
  Linke Strg (halten) Ducken                      Left Ctrl (hold): crouch
  F (nah am Auto)    Einsteigen                   F (near the car): get back in

FREECAM: wie Noclip (W/S/A/D fliegen, Leertaste/Strg hoch/runter, Shift schneller,
Pfeile schauen) / like noclip, arrow keys look.

CONTROLLER (LS = linker Stick gedrückt halten / hold left stick)
  LS + Steuerkreuz ►   Gripline-Menü              LS + D-pad right: Gripline menu
  LS + Steuerkreuz ▲   Noclip                     LS + D-pad up: noclip
  LS + Steuerkreuz ▼   Freecam                    LS + D-pad down: freecam
  LS + Steuerkreuz ◄   Tempomat                   LS + D-pad left: cruise control
  LS + Y               Aussteigen / Laufen        LS + Y: get out / walk
  Y (nah am Auto)      Einsteigen                 Y (near the car): get back in
  Laufen: linker Stick laufen, rechter schauen, RT rennen, A springen, B halten ducken
  Walking: left stick walk, right stick look, RT run, A jump, hold B crouch

MENÜS / MENUS
  Pfeiltasten        Blättern                     Arrow keys: navigate
  Enter              Bestätigen (A)               Confirm (A)
  Rücktaste          Zurück (B)                   Backspace: back (B)
  Esc                Pause / Menü                 Pause / menu
  X / Y              Tasten X / Y                 Buttons X / Y
  Bild↑ / Bild↓      Reiter links / rechts        Page Up / Down: tabs left / right (LB / RB)

Lenkrad: im Azimuth-Launcher einrichten. / Wheel: set it up in the Azimuth launcher.
